The Music Presence logs can be found in the following locations:

**Windows:** `%APPDATA%\Music Presence\presence.log`

**Mac:** `~/Library/Application Support/Music Presence/presence.log`

**Linux:** `~/.local/share/Music Presence/presence.log`


Note that the `~` symbol represents your home directory, e.g. /Users/Me on Mac or /home/me on Linux.

---

The `presence.log` file, is a file that contains the music you have been playing, where the music is comming from, and errors that can help identify issues with the app.

Before sharing these logs publicly, please review them carefully as they may contain personal information such as your computer username, Discord username, Last.fm usernames, or other scrobbling service credentials. Note that passwords, API keys, and other sensitive credentials are never logged.
